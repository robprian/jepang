# 🎌 Jepang — Game Belajar JLPT N3

Game interaktif belajar bahasa Jepang dari nol (hiragana/katakana) sampai lulus JLPT N3.

🌐 Main di: https://robprian.github.io/jepang/

- 21 level: Hiragana, Katakana, Minna no Nihongo L1–L25, Kosakata, Kanji, Grammar, Reading, Listening, Tryout 105 soal
- Audio pengucapan (Web Speech API) + sound effects (Web Audio API)
- Responsive + mobile friendly
